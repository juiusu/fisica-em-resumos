Instruções

Esta lista reúne questões de verdadeiro ou falso sobre calor específico, capacidade térmica, calor latente e troca de calor.

Em cada questão, classifique as cinco afirmações como verdadeiras (V) ou falsas (F). Em várias afirmações é necessário realizar o cálculo para verificar se o valor apresentado está correto: há alternativas com valores certos e com valores errados.

Use \(c_{\text{água}} = 1\,cal/(g \cdot ^\circ C)\), \(c_{\text{azeite}} = 0,47\,cal/(g \cdot ^\circ C)\), \(c_{\text{gelo}} = 0,50\,cal/(g \cdot ^\circ C)\), \(L_f = 80\,cal/g\) e \(L_v = 540\,cal/g\).

Questões

Questão 1 — Calor específico da água

Considere o calor específico da água igual a \(1\,cal/(g \cdot ^\circ C)\) e \(1\,kcal = 1000\,cal\). Julgue as afirmações.

( ) Para aquecer \(2\,kg\) de água de \(20\,^\circ C\) até \(80\,^\circ C\) são necessários \(120\,kcal\).

( ) Para aquecer \(2\,kg\) de água de \(20\,^\circ C\) até \(80\,^\circ C\) são necessários \(60\,kcal\).

( ) Para aquecer \(1\,kg\) de água de \(20\,^\circ C\) até \(80\,^\circ C\) são necessários \(60\,kcal\).

( ) Para aquecer \(500\,g\) de água de \(20\,^\circ C\) até \(80\,^\circ C\) são necessários \(30\,kcal\).

( ) O calor específico da água indica que \(1\,g\) de água precisa de \(1\,cal\) para variar \(1\,^\circ C\).

Questão 2 — Água e azeite

Fornecemos \(20\,kcal\) a \(2\,kg\) de água e a \(2\,kg\) de azeite. Considere \(c_{\text{água}} = 1\,cal/(g \cdot ^\circ C)\), \(c_{\text{azeite}} = 0,47\,cal/(g \cdot ^\circ C)\) e \(1\,kcal = 1000\,cal\). Julgue as afirmações.

A. ( ) A água sofre uma variação de temperatura de \(10\,^\circ C\).

B. ( ) O azeite sofre uma variação de temperatura de aproximadamente \(21,3\,^\circ C\).

C. ( ) O azeite esquenta menos que a água para a mesma quantidade de calor recebida.

D. ( ) Para a mesma variação de temperatura, a água precisa de mais calor que o azeite.

E. ( ) Se fossem \(1\,kg\) de azeite, os \(20\,kcal\) provocariam uma variação de aproximadamente \(42,6\,^\circ C\).

Questão 3 — Capacidade térmica de uma panela

Uma panela de alumínio tem massa \(500\,g\) e calor específico \(0,22\,cal/(g \cdot ^\circ C)\). Considere também \(1\,kcal = 1000\,cal\). Julgue as afirmações.

( ) A capacidade térmica da panela é \(110\,cal/^\circ C\).

( ) Para aquecer a panela de \(20\,^\circ C\) até \(100\,^\circ C\) são necessários \(8,8\,kcal\).

( ) Uma panela de \(1\,kg\) do mesmo alumínio tem capacidade térmica de \(220\,cal/^\circ C\).

( ) Para variar a temperatura da panela em \(10\,^\circ C\) são necessários \(110\,cal\).

( ) A capacidade térmica depende do material e da massa do corpo.

Questão 4 — Fusão do gelo

Considere o calor latente de fusão do gelo \(L_f = 80\,cal/g\) e \(1\,kcal = 1000\,cal\). Julgue as afirmações.

( ) Para derreter \(500\,g\) de gelo a \(0\,^\circ C\) são necessários \(40\,kcal\).

( ) Para derreter \(100\,g\) de gelo a \(0\,^\circ C\) são necessários \(8\,kcal\).

( ) Para derreter \(1\,kg\) de gelo a \(0\,^\circ C\) são necessários \(80\,kcal\).

( ) Durante a fusão, a temperatura do gelo aumenta gradualmente.

( ) Se o calor latente de fusão fosse \(40\,cal/g\), derreter \(500\,g\) de gelo exigiria \(20\,kcal\).

Questão 5 — Vaporização da água

Considere o calor latente de vaporização da água \(L_v = 540\,cal/g\), o calor latente de fusão do gelo \(L_f = 80\,cal/g\) e \(1\,kcal = 1000\,cal\). Julgue as afirmações.

( ) Para vaporizar \(100\,g\) de água a \(100\,^\circ C\) são necessários \(54\,kcal\).

( ) Para vaporizar \(1\,kg\) de água a \(100\,^\circ C\) são necessários \(540\,kcal\).

( ) Vaporizar \(100\,g\) de água exige menos calor do que derreter \(100\,g\) de gelo.

( ) Ao condensar, \(100\,g\) de vapor a \(100\,^\circ C\) liberam \(54\,kcal\).

( ) Para vaporizar \(200\,g\) de água a \(100\,^\circ C\) são necessários \(108\,kcal\).

Questão 6 — Gelo resfriando uma bebida

Colocamos \(100\,g\) de gelo a \(-10\,^\circ C\) em uma bebida. O gelo absorve calor até se transformar em água a \(20\,^\circ C\). O processo ocorre em três etapas. Considere \(c_{\text{gelo}} = 0,50\,cal/(g \cdot ^\circ C)\), \(L_f = 80\,cal/g\), \(c_{\text{água}} = 1\,cal/(g \cdot ^\circ C)\) e \(1\,kcal = 1000\,cal\). Julgue as afirmações.

( ) Aquecer o gelo de \(-10\,^\circ C\) até \(0\,^\circ C\) absorve \(500\,cal\).

( ) A fusão do gelo a \(0\,^\circ C\) absorve \(8\,kcal\).

( ) Aquecer a água resultante de \(0\,^\circ C\) até \(20\,^\circ C\) absorve \(2\,kcal\).

( ) O calor total absorvido pelo gelo é \(10,5\,kcal\).

( ) A maior parte do calor é usada para aquecer a água, e não para a fusão do gelo.

Questão 7 — Troca de calor

Em um calorímetro ideal, misturamos \(200\,g\) de água a \(80\,^\circ C\) com \(200\,g\) de água a \(20\,^\circ C\). Considere \(c_{\text{água}} = 1\,cal/(g \cdot ^\circ C)\). Julgue as afirmações.

( ) A temperatura de equilíbrio é \(50\,^\circ C\).

( ) O calor cedido pela água quente é igual ao calor recebido pela água fria.

( ) A temperatura de equilíbrio seria \(60\,^\circ C\).

( ) Se as massas fossem diferentes, a temperatura de equilíbrio ficaria mais próxima da temperatura da massa maior.

( ) Em um calorímetro ideal, não há perdas de calor para o ambiente.

Questão 8 — Unidades de energia

Sobre as unidades de energia usadas em calorimetria, julgue as afirmações. Considere \(1\,cal \approx 4,18\,J\) e \(1\,kcal = 1000\,cal\).

( ) \(1\,kcal = 1000\,cal\).

( ) \(1\,cal \approx 4,18\,J\).

( ) \(120\,kcal\) equivalem a aproximadamente \(500\,kJ\).

( ) \(1\,cal = 4,18\,kcal\).

( ) \(40\,kcal\) equivalem a aproximadamente \(167\,kJ\).
