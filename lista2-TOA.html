INSTRUÇÕES INICIAIS

Nesta atividade, você vai construir e interpretar gráficos de massa por volume para três substâncias:

  • Água (líquido) – densidade = 1,00 g/cm³
  • Ferro (sólido) – densidade = 7,87 g/cm³
  • Mercúrio (líquido) – densidade = 13,60 g/cm³

Contextualização

Imagine que você tem três cubos de mesmo volume:

  • Um cubo de água (congelada, mas com o mesmo volume)
  • Um cubo de ferro (puro)
  • Um cubo de mercúrio (congelado)

Mesmo tendo o mesmo tamanho, eles têm massas muito diferentes.

Isso acontece porque cada substância tem uma densidade diferente:

  • Quanto mais densa, mais massa ela tem em um mesmo volume.
  • Quanto menos densa, menos massa ela tem em um mesmo volume.

A densidade é uma propriedade característica de cada material.

Como a densidade aparece no gráfico?

Em um gráfico de massa (eixo vertical) por volume (eixo horizontal):

  • A inclinação da reta representa a densidade.

Instruções para construção

  • Use papel quadriculado (milimetrado).
  • Desenhe os eixos:
    • Eixo horizontal (x): Volume (cm³)
    • Eixo vertical (y): Massa (g)
  • Marque os pontos de cada substância no mesmo gráfico.
  • Use cores diferentes para cada substância, exemplo:
    • Azul para a ÁGUA
    • Preta para o FERRO
    • Vermelho para o MERCÚRIO
  • Trace uma reta ligando os pontos de cada substância.
  • Coloque um título no gráfico e uma legenda com as cores.
    • Título: uma identificação do que se trata o gráfico;
    • Legenda: Uma descrição resumida.
