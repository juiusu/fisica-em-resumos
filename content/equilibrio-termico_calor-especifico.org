#+options: toc:2
#+language: pt-BR

* Instruções

Esta lista reúne questões de verdadeiro ou falso sobre equilíbrio
térmico, calor específico, capacidade térmica e trocas de calor entre
dois corpos ou duas substâncias.

Em cada questão, classifique as cinco afirmações como **verdadeiras
(V)** ou **falsas (F)**. Em várias afirmações é necessário realizar o
cálculo para verificar se o valor apresentado está correto: há
alternativas com valores certos e com valores errados.

Considere \(c_{\text{água}} = 1\,cal/(g \cdot ^\circ C)\),
\(c_{\text{azeite}} = 0,47\,cal/(g \cdot ^\circ C)\) e
\(c_{\text{Al}} = 0,22\,cal/(g \cdot ^\circ C)\). Salvo indicação
contrária, não há perdas de calor para o ambiente nem mudança de fase.

* Questões

** Questão 1 — Conceito de equilíbrio térmico
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: facil
:tag: equilíbrio térmico, lei zero, temperatura
:END:

Sobre o equilíbrio térmico, julgue as afirmações.

(   ) Dois corpos colocados em contato trocam calor até que suas temperaturas se igualem.

(   ) No equilíbrio térmico, cessa a troca líquida de calor entre os corpos.

(   ) No equilíbrio térmico, os corpos obrigatoriamente possuem a mesma quantidade de calor.

(   ) A Lei Zero da Termodinâmica permite usar um termômetro para comparar temperaturas.

(   ) Dois corpos com a mesma temperatura possuem necessariamente a mesma energia interna.


** Questão 2 — Mistura de massas iguais de água
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: facil
:tag: equilíbrio térmico, água, temperatura de equilíbrio
:END:

Em um calorímetro ideal, misturam-se \(200\,g\) de água a
\(80\,^\circ C\) com \(200\,g\) de água a \(20\,^\circ C\). Julgue as
afirmações.

(   ) A temperatura de equilíbrio é \(50\,^\circ C\).

(   ) O calor cedido pela água quente é igual ao calor recebido pela água fria.

(   ) A temperatura de equilíbrio seria \(60\,^\circ C\).

(   ) A quantidade de calor cedida pela água quente é \(6\,kcal\).

(   ) A quantidade de calor recebida pela água fria é \(6\,kcal\).


** Questão 3 — Massas diferentes de água
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: medio
:tag: equilíbrio térmico, massa, temperatura de equilíbrio
:END:

Em um calorímetro ideal, misturam-se \(200\,g\) de água a
\(80\,^\circ C\) com \(300\,g\) de água a \(20\,^\circ C\). Julgue as
afirmações.

(   ) A temperatura de equilíbrio é \(44\,^\circ C\).

(   ) A temperatura de equilíbrio fica mais próxima de \(20\,^\circ C\) que de \(80\,^\circ C\).

(   ) A temperatura de equilíbrio seria \(50\,^\circ C\).

(   ) A massa maior sofre menor variação de temperatura que a massa menor.

(   ) Em módulo, o calor cedido pela água quente é maior que o calor recebido pela água fria.


** Questão 4 — Água e azeite
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: medio
:tag: equilíbrio térmico, calor específico, água, azeite
:END:

Em um calorímetro ideal, misturam-se \(200\,g\) de água a
\(80\,^\circ C\) com \(200\,g\) de azeite a \(20\,^\circ C\). Considere
\(c_{\text{azeite}} = 0,47\,cal/(g \cdot ^\circ C)\). Julgue as
afirmações.

(   ) A temperatura de equilíbrio é aproximadamente \(60,8\,^\circ C\).

(   ) A temperatura de equilíbrio fica mais próxima de \(80\,^\circ C\) que de \(20\,^\circ C\).

(   ) O azeite sofre maior variação de temperatura que a água.

(   ) A temperatura de equilíbrio seria \(50\,^\circ C\).

(   ) Para massas iguais, o corpo de maior calor específico sofre a menor variação de temperatura.


** Questão 5 — Metal quente dentro da água
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: dificil
:tag: equilíbrio térmico, alumínio, água, troca de calor
:END:

Uma peça de alumínio de \(100\,g\) a \(200\,^\circ C\) é colocada em
\(500\,g\) de água a \(20\,^\circ C\). Considere
\(c_{\text{Al}} = 0,22\,cal/(g \cdot ^\circ C)\). Julgue as afirmações.

(   ) A temperatura de equilíbrio é aproximadamente \(27,6\,^\circ C\).

(   ) O alumínio cede calor e a água recebe calor.

(   ) A temperatura de equilíbrio seria maior que \(50\,^\circ C\).

(   ) A água sofre uma variação de temperatura de aproximadamente \(7,6\,^\circ C\).

(   ) O alumínio sofre uma variação de temperatura de aproximadamente \(172,4\,^\circ C\).


** Questão 6 — Calor específico e aquecimento
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: medio
:tag: calor específico, água, azeite, Q = mcΔT
:END:

Sobre o calor específico e o aquecimento de substâncias, julgue as
afirmações.

(   ) Para aquecer \(2\,kg\) de água de \(20\,^\circ C\) até \(80\,^\circ C\) são necessários \(120\,kcal\).

(   ) Para aquecer a mesma massa de azeite no mesmo intervalo de temperatura seria necessário menos calor que para a água.

(   ) A água precisa de mais calor que o azeite para sofrer a mesma variação de temperatura.

(   ) O calor específico mede a quantidade de calor por unidade de massa e por unidade de variação de temperatura.

(   ) Quanto maior o calor específico de uma substância, menor o calor necessário para aquecê-la.


** Questão 7 — Determinando um calor específico
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: dificil
:tag: calor específico, equilíbrio térmico, calorímetro
:END:

Uma amostra de \(200\,g\) de uma substância desconhecida a
\(100\,^\circ C\) é colocada em \(400\,g\) de água a \(20\,^\circ C\).
A temperatura de equilíbrio é \(30\,^\circ C\). Julgue as afirmações.

(   ) O calor recebido pela água é \(4\,kcal\).

(   ) O calor específico da substância é aproximadamente \(0,29\,cal/(g \cdot ^\circ C)\).

(   ) O calor específico da substância é aproximadamente \(0,50\,cal/(g \cdot ^\circ C)\).

(   ) A substância poderia ser alumínio, cujo calor específico é aproximadamente \(0,22\,cal/(g \cdot ^\circ C)\).

(   ) Para uma mesma quantidade de calor, quanto maior o calor específico da substância, menor será sua variação de temperatura.


** Questão 8 — Capacidade térmica e calor específico
:PROPERTIES:
:origem: banco-criado
:tipo: verdadeiro_falso
:nivel: medio
:tag: capacidade térmica, calor específico, massa
:END:

Sobre a diferença entre capacidade térmica e calor específico, julgue
as afirmações.

(   ) Capacidade térmica é a quantidade de calor necessária para variar a temperatura de um corpo em \(1\,^\circ C\).

(   ) Calor específico é a capacidade térmica por unidade de massa.

(   ) Um corpo com maior massa, sendo do mesmo material, tem maior capacidade térmica.

(   ) Dois corpos de mesma massa e materiais diferentes têm sempre a mesma capacidade térmica.

(   ) A capacidade térmica depende da massa e do material do corpo.
